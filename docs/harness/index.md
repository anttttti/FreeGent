# Harness

The harness is everything around the model that makes a free or small model usable as an agent. It is shared by the WebUI, TUI and CLI.

| Page | Covers |
|---|---|
| [Tools](/harness/tools) | What the agent can call, and the defaults |
| [Roles and sub-agents](/harness/roles) | Director, Coder, Researcher and parallel workers |
| [Skills and rules](/harness/skills) | Instructions added to the prompt when their trigger matches |
| [MCP servers](/harness/mcp) | External tools through the Model Context Protocol |
| [Context and compaction](/harness/context) | How history is kept within the window |
| [Checks, approval and safety](/harness/checks) | Step validation, completion gates, tool approval, intent validation |

Choosing models and handling rate limits is covered in [Providers and models](/models/). Running code is covered in [Code execution](/code-execution/).
