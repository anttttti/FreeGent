NOTES:
- _toolResultsText: last 5 tool messages, each truncated to 500 chars, joined by '---'.
  Extracts .stdout or .content from JSON tool results, falls back to raw string.
- The trigger condition "bare integer ≥2 digits" targets benchmark tasks that expect
  a numeric answer (AgentBench OS/DB count queries, DSAEval scores, etc.)
- The "not found in recent tool results" pre-check avoids the LLM call when the
  answer is obviously consistent. The judge only runs in the ambiguous middle case.
- _reactiveFired.add('answer_grounding') ensures the judge fires at most once per turn,
  even if the agent re-declares COMPLETED multiple times.
- Companion check: graded_test (pytest IDs in task text → require passing tests before
  COMPLETED). Both write to _gate which is injected as a ~~~guidance~~~ nudge.
